# ZMIX

مكتبة سينمائية لقوائم تشغيل يوتيوب — Android.

ZMIX يحوّل قوائم تشغيل يوتيوب اللي بتضيفها بنفسك لمكتبة مرتبة: كروت للقوائم، تجميع تلقائي لحلقات المسلسلات ومواسمها لما العنوان واضح، وسيبك من الفوضى لما مش واضح (من غير اختراع أسماء أو أرقام حلقات). الأفلام والأغاني تفضل بعناوينها الأصلية زي ما هي.

## الحالة الحالية

**Trial 0.1** — أول نسخة تجريبية: اختبار تشغيل فيديو يوتيوب بمشغّل ZMIX المخصص على الموبايل. الصق رابط فيديو، دوس تشغيل، والتطبيق يوريك كل خطوة. التنزيل من صفحة [Releases](../../releases).

## تصميم ومراجع

الشكل والمشغّل مستوحيين من [Zangetsu](https://github.com/Spyou/Zangetsu) (GPL-3.0) وفكرة تشغيل يوتيوب داخل التطبيق من [Cloudstream](https://github.com/recloudstream/cloudstream) (GPL-3.0). الكود هنا مكتوب لمشروع ZMIX مع عزمنا توثيق أي جزء مأخوذ حرفيًا وشروطه أول بأول.
