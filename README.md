# ZMIX

مكتبة سينمائية لقوائم تشغيل يوتيوب — Android.

ZMIX يحوّل قوائم تشغيل يوتيوب اللي بتضيفها بنفسك لمكتبة مرتبة: كروت للقوائم، تجميع تلقائي لحلقات المسلسلات ومواسمها لما العنوان واضح، وسيبك من الفوضى لما مش واضح (من غير اختراع أسماء أو أرقام حلقات). الأفلام والأغاني تفضل بعناوينها الأصلية زي ما هي.

### حدود معروفة

- الجودة حاليًا أعلى صيغة مدمجة (صوت+صورة مع بعض) اللي يوتيوب بيقدمها للفيديو — ودي عادة أقل من أعلى دقة متاحة. اختيار الجودة الحقيقي جاي مع شاشة المشغّل.
- يوتيوب بيغيّر قيوده من وقت للتاني؛ التشغيل بيعتمد على مكتبة `youtube_explode_dart` النشطة، وأي تغيير من يوتيوب ممكن يأثر مؤقتًا.
- التحديثات من 0.2 فصاعدًا بتحافظ على بياناتك (توقيع ثابت). الترقية من Trial 0.1 لـ 0.2 محتاجة إزالة 0.1 الأول (مفتاح توقيع مؤقت مختلف، و0.1 مكانش فيها بيانات أصلًا).

## البناء

- Flutter (stable)، Dart، media_kit للتشغيل، youtube_explode_dart لبيانات يوتيوب.
- CI (`.github/workflows/build.yml`): `workflow_dispatch` بوسم الإصدار → APK بمعمارية arm64 موقّع بمفتاح ثابت (موجود في أسرار المستودع، المفتاح نفسه مش متنشر) → نشر في Releases.
- معاينة ويب للواجهة فقط (مش إثبات تشغيل) على GitHub Pages.
